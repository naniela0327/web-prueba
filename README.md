# Portafolio de Ruth Eliana Villota Mejía

Portafolio pedagógico interactivo para GitHub Pages.

## Publicación
1. En GitHub abre **Settings → Pages**.
2. En **Build and deployment → Source**, selecciona **GitHub Actions**.
3. Guarda.
4. Ve a **Actions → Deploy Ruth portfolio to GitHub Pages** y espera la ejecución.

El workflow ya incluye `pages: write`, `id-token: write` y el auto-enable de Pages. GitHub debe permitir que la cuenta configure Pages una primera vez.

## Contenido
- Presentación personal y mirada pedagógica.
- Formación 2005, 2019 y Licenciatura en curso 2026.
- Aula Hospitalaria: 6 experiencias.
- Entornos de protección: 3 experiencias.
- Fichas con situación, pregunta, propósito, actividades, materiales, duración, adaptaciones, evidencia, familia y cuidado.
- Evidencias visuales organizadas a partir de las 16 láminas de la presentación.
- Fotografía de Ruth tomada de la portada original.
